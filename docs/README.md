# Documentation

This directory contains the engineering documentation for Intellery.

## Structure

### adr/

Architecture Decision Records documenting important technical decisions.

### architecture/

High-level explanations of how the system is designed.

### api/

API specifications and endpoint contracts.

### diagrams/

Architecture and system diagrams.

### development/

Developer onboarding, local setup, coding standards, and project conventions.

---

Documentation should evolve alongside the codebase.

Every major feature should update the relevant documentation before implementation.
